## Konto und Lizenzen

- [ ] Benutzerkonto anlegen (Namenskonvention beachten)
- [ ] Gruppen gemäß Abteilung zuweisen
- [ ] Microsoft-365-Lizenz zuweisen
- [ ] MFA-Registrierung vorbereiten

## Arbeitsplatz

- [ ] Gerät vorbereiten und inventarisieren
- [ ] Drucker und Netzlaufwerke prüfen
- [ ] Zugangsdaten sicher übergeben (nicht per E-Mail)

## Erster Tag

- [ ] Erstanmeldung begleiten, Kennwort ändern lassen
- [ ] Kurzeinweisung IT-Sicherheit
